# Student Management System

A simple Student Management System built using PHP, MySQL, Bootstrap.

## Features
- Add Student
- Edit Student
- Delete Student
- Search Student
- View Student
- Timetable Button (Subject, Day, Time)

## Tech Stack
- PHP
- MySQL
- Bootstrap
- XAMPP

## How to Run
1. Clone repo
2. Move folder to htdocs
3. Import database
4. Run localhost/project-name
